✦ Installation

Lancer le projet
en 5 étapes.

Prérequis : PHP 8.2+ · MariaDB 10.4+ · Composer · Compte Stripe

01
📥
Cloner le repo
git clone https://github.com/
zakariyaaaaaa/Taghazout_v2.git
cd Taghazout_v2
02
📦
Installer les dépendances
composer install
03
⚙️
Configurer .env
DB_HOST=localhost
DB_NAME=taghazout
STRIPE_KEY=sk_test_...
04
🗄️
Importer la base
mysql -u root -p taghazout
< database/taghazout.sql
05
🚀
Démarrer le serveur
php -S localhost:3000

# → http://localhost:3000
